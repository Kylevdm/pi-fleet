# pi-fleet

**Design stage.** This repository holds no module content yet.

pi-fleet will be the standalone TypeScript home of Fleet: a delegation module
that hands suitable work to cheaper models when doing so is expected to save
primary-orchestrator tokens, collects compact evidence for the primary to
accept, and returns work to the primary after one escalation when delegated
work does not meet the contract.

The design is being worked out in the open, as a Wayfinder map in
[Kylevdm/skills](https://github.com/Kylevdm/skills) — see
`docs/wayfinder/fleet-redesign.md` there for the map and its resolved tickets.
That map moves onto this repository's issue tracker once it is agreed; the
module content follows after.
