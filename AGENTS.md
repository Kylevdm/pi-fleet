## Agent skills

### Issue tracker

Issues live as GitHub Issues in `Kylevdm/pi-fleet` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout — `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Implementation

Implement work in this repository with Matt Pocock's `/implement` skill: `/tdd` at the seams the ticket agrees, typecheck and single test files while working, the full suite once at the end, then `/code-review` before committing. Multi-ticket work follows `implement-spec`.
